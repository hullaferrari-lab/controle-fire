# Segurança

Não publique PINs, tokens, chaves ADB, chaves de assinatura, gravações ou dados de conta em issues. Para relatar uma vulnerabilidade, use a aba **Security → Advisories → Report a vulnerability**, se o mantenedor disponibilizar esse recurso. Caso não esteja disponível, abra apenas uma issue solicitando um canal reservado, sem detalhes sensíveis.

Use ADB somente em redes de confiança e desative a depuração quando não precisar dela. O app fixa o certificado TLS do Fire TV no primeiro pareamento e recusa mudanças posteriores; uma troca legítima de certificado exige novo pareamento. DIAL de reativação é HTTP local e não envia o token do controle.

O projeto está em versão inicial e não oferece prazo garantido de correção.
